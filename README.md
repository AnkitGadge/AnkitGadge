## Snake Game

A playable browser-based Snake game is available in `snake-game.html`.

### Run

Open `snake-game.html` in any modern browser.

### Launch locally

From the repository root, run either:

```bash
./launch-snake.sh 8000
```

or (if the script is unavailable in your environment):

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/snake-game.html`.
